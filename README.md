# 瓶中沧海 · 3D 玻璃瓶

真 3D 微缩场景：横卧玻璃瓶内，Gerstner 波海面、珊瑚灯塔岛、三桅帆船绕岛航行、水下宝箱/沉锚/双耳瓶/气泡；瓶外软木塞+红蜡+吊牌、木托架、旧书、黄铜望远镜。

## 特性
- **真 3D 菲涅尔玻璃瓶**（自定义 shader：边缘光 + 高光）
- **360° 拖动环视** + 滚轮缩放，闲置自动旋转
- **实时 FPS** 显示
- **风暴**（按钮或按住空格）：浪涌 + 瓶体摇晃（瓶内水面保持水平）
- **夜色**按钮：昼夜切换，灯窗/灯塔/宝箱发光增强
- 一切元素封闭在瓶内

## 运行
打开 `index.html` 或静态托管。构建：`pnpm install && pnpm run build`。
技术：Three.js r185 + esbuild。
